# Registros de decisiones de arquitectura (ADR)

Un archivo por decisión, numerado, con contexto, decisión, alternativas descartadas y consecuencias. Se escriben cuando la decisión está tomada y probada (el spike de septiembre de 2026 es la fuente de la mayoría). Un ADR no se edita para cambiar la decisión: se escribe otro que lo sustituye y se marca el antiguo como sustituido.
